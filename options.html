Settings setup guide Start here for 9Router, automatic startup, and optional tools.

Subtitles, reading modes, and your local flashcard collection work without AI setup. To use Sensei Chat and AI grammar explanations, connect 9Router below.

Connect your AI tutor

  1. Install and start 9Router. Install a current Node.js LTS release, then run these commands in a terminal: 
    npm install -g 9router
9router
  2. Connect a provider. Open the 9Router dashboard, enable a provider, and copy your router API key if router authentication is enabled. Provider credentials belong in 9Router.
  3. Fill in 9Router AI below. For this computer, keep http://127.0.0.1:20128/v1 as the API Base URL. Paste the router key into 9Router API Key. Use your hosted router's API URL if it runs elsewhere.
  4. Choose, test, and save. Choose a model from Available Models, which loads from your router when this page opens. Click Load Models to refresh it or allow access to a hosted router. The selected ID, including its provider prefix, fills Model or Combo. You can also type a combo name there. Click Test 9Router; after a successful reply, click Save Settings at the bottom of this page. Testing sends a real AI request and does not save the form.

Open or refresh a YouTube video with Japanese captions, click a word, and try Ask Sensei or Sensei Chat.

Start 9Router automatically

In 9Router, choose Hide to Tray (Background) if shown. Open its tray menu and choose Enable Auto-start to launch it when you log in. Tray support depends on your desktop. If you already use a login service, keep that as your startup method.

The extension needs 9Router running for AI. Start parser server when a video plays controls the separate Japanese parser.

Add optional tools when you need them

  • Anki: install AnkiConnect (add-on code 2055492159), restart Anki, and keep it open. Create a deck whose name matches Anki Target Deck Name. Keep http://127.0.0.1:8765 for local Anki, click Test AnkiConnect, and save.
  • Japanese Parser: the companion LangPlay backend adds contextual Sudachi readings. Its default URL is http://127.0.0.1:8000. Follow the parser and local launcher setup guide before enabling automatic parser startup, then use Test Parser. Without it, you can turn off parser startup and use fallback readings.
  • Reading and cards: choose Furigana, Romaji, or Hidden as your default reading mode, then save. Export TSV File downloads your locally saved cards for later import into Anki. Clear Cards removes the local collection after confirmation.

If the AI test fails

Check that the dashboard opens, the API URL ends in /v1, the router key is correct, and the selected model works in 9Router. A loaded model list alone does not confirm that an AI request will work.

If OpenCode reports wreq-js unavailable, install its missing dependency with the command for your platform, then restart 9Router and test again. These commands use 9Router's default data directory.

Linux / macOS:

npm --prefix "$HOME/.9router/runtime" install wreq-js

Windows PowerShell:

npm --prefix "$env:APPDATA\9router\runtime" install wreq-js

A hosted endpoint may ask for browser access when you test or save. Allow access to your chosen server to finish setup.
